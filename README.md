# FileScope - 本地文件名比对与统计工具

`FileScope` 是运行在用户电脑上的本地文件名分析与比对工具。页面中的所有“选择本地文件夹”按钮都会打开当前 Windows 会话的原生目录选择窗口，并将所选目录的完整绝对路径用于扫描、比对和导出。

---

## 🌟 核心特性

1. **单目录前缀与层级统计 (Prefix & Hierarchy Analytics)**
   - **多前缀智能匹配**：支持标签式多前缀输入，秒级统计各前缀文件数量、占用大小、百分比占比及扩展名分布。
   - **自动前缀发现**：一键智能检测目标目录中高频使用的文件名前缀模式。
   - **最深层（叶子）目录统计**：自动识别不含子文件夹的最深层目录，精确展示各目录文件数、主要类型与合计数据（总计、均值、极值）。
   - **高级过滤**：支持包含/排除正则表达式、隐藏文件过滤与最大递归深度限制。

2. **双目录文件名差异比对与筛查 (Dual-Folder Diff Tracker)**
   - **多维度比对模式**：
     - **相对路径模式**：严格匹配 `path/to/file.ext`。
     - **扁平文件名模式**：忽略子目录层级，全量检索是否存在同名文件。
     - **前缀剥离模式**：去除不同前缀后比对主干文件名。
   - **五大状态精准归类**：
     - 🟢 **完全一致 (Exact Match)**：两端路径与属性完全吻合。
     - 🔵 **仅在目录 A (Only in A)**：目录 B 缺失该文件。
     - 🔴 **仅在目录 B (Only in B)**：目录 A 缺失该文件。
     - 🟡 **属性差异 (Diff Attr)**：同名同路径，但文件大小或修改时间不同。
     - 🟣 **路径漂移 (Moved Path)**：同名文件位于不同子目录。
   - **实时筛查与批量导出**：
     - 一键按状态筛选（如只看缺失项或差异项）。
     - 支持全文检索与模糊搜索。
     - 一键复制差异文件名至剪贴板，支持导出带 UTF-8 BOM 的 CSV 或 JSON 格式报告。

3. **文件名模板拆分 Excel 导出 (Filename Template Export)**
   - 选择根目录后，仅读取叶子文件夹中的文件，忽略根目录直系文件。
   - 按自定义字段顺序和分隔符拆分文件名主体，扩展名不参与拆分。
   - 支持按文件夹分工作表或汇总到单工作表，不匹配文件保留并标记。

4. **极简部署与现代化交互**
   - **零重型依赖**：基于 Python FastAPI + 原生异步文件系统扫描，单命令即可启动。
   - **Anti-AI-Slop 现代化 UI**：深空暗色 (OLED) 与清新明亮双主题，流畅响应式交互，分页虚拟列表支持上万条数据极速渲染。
   - **Windows 原生目录选择**：直接选择用户电脑上的文件夹，保留完整绝对路径，并可从结果表中打开资源管理器。

## 🚀 快速启动

### 方式一：直接运行 (推荐)
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务 (默认端口 8000)
python app.py

# 指定端口
python app.py --port 8080
```
访问浏览器：`http://127.0.0.1:8000`。原生目录选择窗口属于启动 FileScope 的当前 Windows 用户会话，因此本项目不再按远程服务器或容器化网页使用。

## 🔧 RESTful API 接口说明

| 方法 | 路径 | 功能描述 |
| :--- | :--- | :--- |
| `POST` | `/api/scan` | 单目录统计：计算前缀命中、叶子目录清单与聚合汇总 |
| `POST` | `/api/compare` | 双目录比对：根据模式比对目录A与B，返回差异状态项与汇总指标 |
| `POST` | `/api/select-local-folder` | 打开本机原生文件夹选择窗口并返回完整绝对路径 |
| `POST` | `/api/open-system-folder` | 在运行服务的主机系统文件管理器中打开目录；统计与对比清单中的路径均支持点击唤起 |
| `POST` | `/api/export-filename-xlsx` | 按自定义分隔符拆分叶子目录文件名并导出 Excel 工作簿 |
| `GET` | `/api/health` | 本地服务健康状态与环境信息查询 |
